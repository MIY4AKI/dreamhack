# 정적 분석
- **프로그램을 실행하지 않고 분석하는 것**

=> 프로그램을 실행시킨다고 해도 모든 코드가 실행될 것이라고 보장할 수 없음. 또한, 특정 환경에서만 실행되는 프로그램이라 실행하기 어려운 상활이 생길수도(또는 해킹 위험)

<br>

- 그래서 실행하지 않고 프로그램의 동작을 분석하기 위해서는 컴퓨터가 이해할 수 있는 언어인 -*기계어*- 를 분석해야 함

- 아니면 컴파일 과정을 역으로 수행 => 기계어를 사람이 이해할 수 있는 소스 코드로 변환하여 분석

이번 시간에는 디컴파일러를 이용해 프로그램의 기계어를 C 수준의 프로그래밍 언어로 변환하여 프로그램 정적 분석을 실행할 것임

<br>
