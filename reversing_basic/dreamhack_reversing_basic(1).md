## 확장자

|확장자|분류|용도|
|---|---|---|
|.txt|문서 파일|일반 텍스트 저장, 메모장 등 기본 텍스트 편집기로 수정 가능
|.doc|문서 파일| 워드 프로세서에서 작성 및 편집하는 문서로 다양한 요소(이미지, 텍스트 등) 포함 가능|
|.pdf|문서 파일| 문서의 레이아웃과 서식 유지& 다양한 기기에서 동일하게 표시되는 파일 포맷|
|.jpg|그림 파일|사진이나 디지털 이미지 저장에 주로 사용, 손실 압축 방식|
|.png|그림 파일|투명도 지원이 가능한 이미지 포맷, 웹 그래픽 및 아이콘에 사용|
|.gif|그림 파일|간단한 애니메이션이나 짧은 동영상 효과에 사용, 색상 제한 => 단순 그래픽에 적합|
|.exe|실행 파일|Windows 운영체제에서 실행 가능한 프로그램 파일, 응용 프로그램이나 설치 프로그램 실행에 사용됨|
|.msi|실행 파일|Windows Installer 패키지 파일, 소프트웨어 설치 및 배포에 사용|
|.bat|실행 파일|여러 명령어를 순차적으로 실행할 수 있는 배치 파일, Windows 환경에서 자동화 작업 등에 사용|
|.zip|압축 파일|여러 파일이나 폴더를 하나의 파일로 묶어 저장하며, 용량을 줄이거나 전송 시 편리하게 사용됨.|

## 컴퓨터의 데이터 저장 방식

### 2진법, 16진법
- 데이터를 저장할 땐  2진법, 사람에게 표시할 땐 가독성을 좋게 하기 위해 16진법 사용
    - 일반적으로 한 글자를 표현하기 위해 1B에 저장


## HxD 편집기
- 파일에 담긴 데이터를 아스키 등으로 인코딩하지 않고 **날것의 데이터 그대로 확인할 수 있고 데이터를 고칠 수 있는 편집기**

    => 실행파일들을 열어보면 처음 시작이 4D 5A 78 00 으로 시작함
    =>
    이게 헤더(Header)의 일부임

<br>

### Header란?
- 파일이나 데이터 구조의 맨 앞 부분에 위치하는 메타데이터. 해당 파일의 형식, 구조, 속성 등에 대한 정보를 담고 있음.
- Windows 실행파일은 'MZ헤더' 라는게 있음. 이는 4D 5A로 시작함
- 헤더에는 식별자 뿐만 아니라 프로그램이 메모리에 어떻게 로드되어야 하는지, 어떤 리소스를 사용하는지, 어디서 실행을 시작해야 하는지 등 중요한 정보가 포함되어 있음(Header => 설명서)

## 어셈블리어(Assembly)
- 실행 파일 => 컴퓨터가 실행해야 할 명령어를 담은 데이터 덩어리
- 여기서 명령어가 우리가 보고있는 데이터이며, 이를 기계어라고 함

<br>

|기계어|어셈블리어|
|---|---|
|48 c7 c0 02 13 00 00|mov rax, 0x1302|
|48 83 c3 05|add rbx, 5|
|0f 84 ae 00 00 00|je 0xb4|
