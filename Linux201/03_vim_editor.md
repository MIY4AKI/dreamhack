## 1. CLI에서 편집기가 필요한 이유

문서 편집기(Text Editor)는 텍스트 파일을 작성·수정하는 프로그램이다. GUI에서는 클릭과 커서 이동으로 원하는 위치를 쉽게 고칠 수 있지만, 셸에서 `cat` 등을 이용해 표준 입력을 파일로 저장하는 방식은 이미 작성한 여러 줄의 중간을 편집하기에 불편하다.

CLI 편집기는 이 문제를 해결한다. Ubuntu에서 볼 수 있는 대표적인 편집기는 `vi`/`vim`, `emacs`, `nano`다. 이 강의는 Vim의 기본 조작을 다룬다. 키보드 조작에 익숙해지면 마우스 없이 빠르게 수정할 수 있고, GUI IDE에서도 Vim 확장 기능으로 같은 조작법을 사용할 수 있다.

## 2. vi·Vim과 모드

### vi와 Vim

- **vi**: visual editor에서 유래한 이름으로, William Nelson Joy(Bill Joy)가 개발했다. Vim·Neovim 등 후속 편집기의 기반이다.
- **Vim**: vi를 발전시킨 편집기다. 강의는 이름을 visual editor improved로 풀어 설명한다. 일반적으로는 **Vi IMproved**라는 이름으로 알려져 있다.

### 강의에서 사용하는 두 상태

- **명령 모드**: 실행 직후의 상태다. 키를 누르면 문자 입력이 아니라 이동·복사·저장 등의 명령으로 해석한다. Vim의 용어로는 주로 Normal 모드에 해당한다.
- **편집 모드(Insert)**: 문자를 입력하는 상태다. 화면 아래 `-- INSERT --` 표시로 확인한다.

명령 모드에서 `i`, `a`, `I`, `A` 등의 키로 편집 모드에 들어간다. 편집 모드에서 `Esc`로 명령 모드로 돌아온다. 강의는 `Ctrl+C`도 사용한다.

> **보충**: Vim에는 Visual 모드와 `:`로 여는 명령줄 모드 등도 있다. 강의의 두 모드는 입문용 구분이다. `Ctrl+C`와 `Esc`는 세부 동작이 완전히 같지 않으므로 평소에는 `Esc`를 기본으로 익혀 두면 좋다.

## 3. 입력과 커서 이동

### 입력 시작 위치

- `i`: 현재 커서 **앞**에서 입력한다.
- `a`: 현재 커서 **뒤**에서 입력한다.
- `I`: 현재 줄의 첫 비공백 문자 위치에서 입력한다.
- `A`: 현재 줄의 끝에서 입력한다.

강의에서 `I`를 “줄 맨 앞”으로 설명하지만, 들여쓰기 공백이 있는 줄에서는 첫 비공백 문자 위치라는 차이를 기억한다.

### 이동 명령

- `w`: 다음 단어의 시작으로 이동한다.
- `W`: 공백으로 구분되는 다음 큰 단어(WORD)의 시작으로 이동한다.
- `b`: 이전 단어의 시작으로 이동한다.
- `B`: 공백으로 구분되는 이전 WORD의 시작으로 이동한다.
- `gg`: 문서의 첫 줄로 이동한다.
- `G`: 문서의 마지막 줄로 이동한다.
- `^`: 현재 줄의 첫 비공백 문자로 이동한다.
- `$`: 현재 줄의 끝으로 이동한다.
- 화살표: 한 칸씩 또는 한 줄씩 이동한다.

`w`와 `W`, `b`와 `B`는 문장부호 등을 단어의 경계로 다루는 방식이 다르다. 대문자 버전은 공백을 주요 경계로 삼는다.

> **보충/정정**: `^`는 줄의 문자상 첫 칸이 아니라 첫 **비공백** 위치다. 줄 첫 칸은 `0`으로 이동할 수 있다. `I` 역시 첫 비공백 위치를 기준으로 한다. [Vim 이동 도움말](https://vimhelp.org/motion.txt.html), [Vim 입력 도움말](https://vimhelp.org/insert.txt.html)

## 4. 복사·변경·되돌리기

- `y`: 지정한 범위를 복사(yank)하는 연산자다. 보통 이동 명령 등과 결합한다.
- `yy`: 현재 줄을 복사한다.
- `p`: 저장된 내용을 커서 뒤에 붙인다. 줄 단위로 복사했다면 현재 줄 아래에 붙인다.
- `dd`: 현재 줄을 삭제하고 레지스터에 보관한다. 이후 `p`로 다시 붙일 수 있어 줄 단위 잘라내기처럼 사용할 수 있다.
- `c`: 범위를 지우고 **입력 모드로 들어가는 변경(change) 연산자**다. 강의의 “잘라내기”라는 설명만으로 기억하지 않는다.
- `u`: 이전 변경을 취소한다.
- `Ctrl+R`: 취소한 변경을 다시 실행한다.

> **보충/정정**: `c`는 단독으로 일반적인 GUI 잘라내기 버튼처럼 동작하는 명령이 아니다. 범위 지정이 필요한 변경 연산자이며, 삭제된 텍스트를 보관한 뒤 입력을 시작한다. 예를 들어 `cw`는 단어 범위를 변경하고 `cc`는 줄을 변경한다. [Vim 공식 도움말](https://vimhelp.org/change.txt.html)

강의 화면은 `printf` 줄에서 `yy` 다음 `p`를 눌러 동일한 줄을 복제한 결과, `u`로 한 줄을 되돌린 결과, `Ctrl+R`로 복제를 다시 실행한 결과를 순서대로 보여 준다.

## 5. 검색

명령 모드에서 다음처럼 입력한다.

```vim
/Hello
```

- 입력 중 검색 대상이 강조되는 화면을 볼 수 있다.
- `Enter`로 검색어를 확정한다.
- `n`: 현재 검색 방향으로 다음 일치 항목으로 이동한다.
- `N`: 반대 방향의 일치 항목으로 이동한다.

강의는 복제된 `Hello` 문자열들을 `n`과 `N`으로 왕복하는 모습을 보여 준다. 검색 강조 표시가 Enter 후 남아 있는지는 설정에 따라 다를 수 있다. 강조 표시와 커서 위치를 구분한다.

## 6. 저장·종료

명령 모드에서 `:`를 누르면 아래쪽 명령줄에 명령을 입력할 수 있다. 입력 후 `Enter`로 실행한다.

- `:w <파일 이름>`: 이름을 지정해 저장한다.
- `:w`: 현재 파일 이름으로 저장한다. `vim <파일 이름>`으로 열었거나 이미 이름을 지정한 경우 사용한다.
- `:q`: 종료한다. 저장되지 않은 수정 내용이 있으면 종료를 거부할 수 있다.
- `:q!`: 수정 내용을 저장하지 않고 종료한다. 저장하지 않은 작업을 잃는다.
- `:wq`: 저장하고 종료한다.

파일 이름 없이 `vim`만 실행한 뒤 바로 `:w`를 쓰면 이름이 없다는 오류가 난다. 강의에서는 `:w hello.c`로 이름을 지정해 해결한다. `.c` 확장자로 저장한 뒤 C 문법 강조가 적용된 화면도 보여 준다.

## 7. 강의 실습 전체 흐름

### ① 편집기를 실행하고 입력하기

```bash
vim
```

`a`를 누르고 `-- INSERT --` 표시를 확인한 뒤 아래 코드를 입력한다.

```c
#include <stdio.h>
int main()
{
    printf("Hello Vim!\n");
}
```

입력 후 `Esc`(강의에서는 `Ctrl+C`)로 명령 모드로 돌아온다.

### ② 이동 연습

1. `gg`로 맨 위로 올라간다.
2. `w`로 단어 단위로 이동해 `{`까지 이동한다.
3. 화살표로 `printf`의 `p` 위치로 이동한다.
4. `^`와 `$`로 줄의 첫 비공백 위치와 마지막 위치를 비교한다.

강의 화면에서 작은 밑줄은 현재 커서 위치를 나타낸다.

### ③ 복사·취소·재실행

1. `printf` 줄에서 `yy`를 누른다.
2. `p`를 눌러 동일한 줄을 아래에 붙인다.
3. `u`로 복제를 취소한다.
4. `Ctrl+R`로 다시 적용한다.

### ④ 검색

`/Hello` → `Enter` → `n` → `N`으로 다음/이전 검색 결과를 확인한다.

### ⑤ 저장하고 실행 결과 확인

```vim
:w hello.c
:wq
```

셸로 돌아온 뒤 강의는 다음 명령으로 생성된 파일과 프로그램 출력을 확인한다.

```bash
ls -al
gcc -o hello hello.c && ./hello
```

`gcc -o hello hello.c`는 `hello.c`를 컴파일해 `hello` 실행 파일을 만들고, 컴파일이 성공하면 `./hello`가 실행된다. 프로그램은 `Hello Vim!`를 출력한다. `printf` 줄의 복제 상태에 따라 출력 횟수는 달라질 수 있다.
